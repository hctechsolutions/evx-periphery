# Evx Finance

Evx Finance is a next-generation decentralized exchange protocol designed to deliver maximum efficiency, mathematical precision, and fully on-chain governance.

Inspired by the complexity and order of the cosmos, Evx aims to scale, secure, and empower modern financial ecosystems through a seamless and secure decentralized trading experience.

---

## What is Evx?

Evx is an advanced **DeFi** protocol that allows anyone to swap digital assets or provide liquidity in an efficient, transparent, and community-driven way. Unlike traditional AMMs, Evx offers:

- Concentrated liquidity for better capital efficiency
- Transparent, community-driven governance (DAO)
- On-chain price oracles for accurate, tamper-resistant pricing
- A high-security architecture built for the long term

---

## Why It Matters

The decentralized finance space is filled with protocols that suffer from inefficiency, limited automation, and poor risk mitigation for liquidity providers.  
Evx Finance addresses these limitations through three core innovations:

### 1. Adaptive On-chain Oracle

A dynamic oracle system that adjusts observation frequency based on real-time market volatility.

**How it works:**
- In calm markets, observation frequency is reduced to save gas.
- In volatile conditions, frequency increases automatically for higher TWAP precision.
- Constantly monitors price standard deviation to dynamically adjust the recording interval.

**Benefits:**
- Significant gas savings in stable periods.
- Greater price accuracy in critical moments.
- Highly reliable for arbitrage, lending, and DeFi integrations.

---

### 2. Auto-Balanced Liquidity

A smart liquidity management system that recommends or adjusts the ideal price ranges (ticks) for liquidity providers.

**How it works:**
- Analyzes historical and real-time data to identify optimal allocation zones.
- Uses regression or lightweight on-chain models to predict price behavior.
- Suggests wider ranges during high volatility and tighter ranges when stable.
- Optional “auto-adjust” mode for dynamic rebalancing via smart contracts.

**Benefits:**
- Reduces idle capital and improves capital efficiency.
- Minimizes impermanent loss risk through intelligent allocation.
- Makes LP experience smarter and more accessible.

---

### 3. Smart Impermanent Loss Protection

An embedded system that uses decentralized derivatives to provide automated IL protection.

**How it works:**
- A portion of protocol fees funds put/call options for hedging.
- Hedge coverage dynamically adapts to position size and predicted volatility.
- Protection triggers automatically when IL surpasses a safe threshold.
- Integrates with protocols like Opyn, Lyra, or Ribbon Finance for on-chain execution.

**Benefits:**
- Innovative and sustainable protection mechanism.
- Attracts professional and institutional LPs by reducing risk.
- Reinforces Evx’s positioning as a security-first protocol.

---

**Together, these features make Evx more than just an AMM — it's a smart, adaptive, and resilient foundation for the next generation of DeFi bringing strategy, sustainability, and clarity to decentralized finance.**

# Technical Details

This repository contains the implementation of the smart contracts that comprise the system, covering governance, liquidity, rewards, vesting, and price oracle modules. The architecture leverages OpenZeppelin standards and libraries, with governance mechanisms inspired by OpenZeppelin's Governor.

---

## Prerequisites

- [Foundry](https://getfoundry.sh/) – a tool for developing, testing, and deploying Solidity contracts  
- [Git](https://git-scm.com/)  
- [Anvil](https://book.getfoundry.sh/reference/anvil) – Foundry's local Ethereum node

---

## Installation

1. Clone the repository:

   ```bash
   git clone [https://github.com/defi/Evx_contracts.git]
   cd Evx_contracts
   ```

2. Ensure you have Foundry installed and updated:

   ```bash
   forge --version
   ```

3. Start a local Anvil node:

   ```bash
   anvil
   ```

---

## Running Tests

The tests are written using Foundry's testing framework. To run the tests:

1. Compile the contracts:

   ```bash
   forge build
   ```

2. Run the tests:

   ```bash
   forge test
   ```

Ensure that all tests pass before proceeding with deployment.

---

## Contract Deployment

Deployment is handled via Foundry scripts located in the `scripts` folder. The main deploy script is `DeployV<version>.s.sol`.

To deploy the contracts on a local network using Anvil:

1. Compile the contracts (if not already compiled):

   ```bash
   forge build
   ```

2. Run the deploy script using Anvil as your local RPC:

   ```bash
   forge script scripts/DeployV<version>.s.sol --fork-url http://127.0.0.1:8545 --broadcast
   ```

   - Replace the RPC URL if necessary.
   - The `--broadcast` flag sends transactions to the network.

Review the contents of `DeployV<version>.s.sol` for details on the deployment order and parameters used for each contract.
